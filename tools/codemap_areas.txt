# The code map's areas (to-do #109), read by tools/codemap.py. Each area lists every place it has in every file, the
# small ones too, so a session that changes one part finds all of it: `py tools/codemap.py AREA` shows them with their
# current lines. Places are named, never numbered, so this list survives edits. docs/code-map.md says how to use it.
#
#   [name] one line: what the area is
#   path: places in that file, separated by spaces; more lines for the same file start with spaces
#   changelog: a regular expression that finds the area's notes in the board's CHANGELOG
#
# A place is one of:
#   name           a top-level function, const, let, class or statement (JS); a def, class, Class.method or variable (Python)
#   #id            a markup id: the element (id="...") and the CSS rules of that id
#   .class         the CSS rules of that class (`.cap` takes .cap.big and .cap:hover too), and the rules that name it inside
#                  another selector (#cardBox .cCr)
#   css:selector   the CSS rules of an element or another selector (css:body, css:body.lite, css:[hidden])
#   @name          a CSS @keyframes
#   /path          a relay endpoint or address: every line naming it (in serve.py its handler and the path lists)
#   "text"         the lines containing that text (README bullets, history notes, a test's comment); 'text' if it has a "
# A + in front (+planeBody) marks a place another area owns that this one reaches into: it shows with the owner's name.
# [every-change] lists what every change goes with (the version, the stamps); each area's page ends with it.
#
# Every top-level function, const, let and class in test/index.html, tools/app/main.js and relay/serve.py, and every CSS
# rule of the board and tools/app/head.html, must be in an area (an item may be in several). `py tools/codemap.py --check`
# (smoke.py --syntax runs it) names what isn't, and any place listed here that no longer exists. Top-level statements go
# with the function above them (or the one their first line names) unless an area names them. i18n rows and most
# docs/history.md entries aren't listed: the tool finds them from the area's code.
